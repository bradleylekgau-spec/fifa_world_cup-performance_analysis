# ⚽ 2022 FIFA World Cup Data Analytics Project

## 📌 Project Overview

This project analyses 2022 FIFA World Cup performance data to identify key insights into team performance, player contributions, attacking efficiency, and defensive performance.

The project demonstrates an end-to-end data analytics workflow using **Python, SQL, and Microsoft Power BI**, transforming raw football data into meaningful insights through data cleaning, analysis, and interactive visualisation.

## 🎯 Project Objectives

- Clean and prepare the World Cup dataset for analysis.
- Explore player and team performance using Python.
- Use SQL to query, aggregate, and analyse football statistics.
- Build an interactive Power BI dashboard to communicate findings.
- Identify top-performing players and compare their contributions and efficiency.
- Evaluate attacking and defensive performance metrics.
- Present actionable insights through a dedicated findings page.

## 🔄 Project Workflow

### 1. Data Collection and Understanding

- Imported the FIFA World Cup dataset.
- Examined the dataset's structure, columns, and data types.
- Identified the variables relevant to player and team performance.

### 2. Data Cleaning Using Python

- Checked for missing values and duplicate records.
- Reviewed data types and corrected inconsistencies where necessary.
- Prepared the dataset for further analysis.
- Used Pandas and NumPy for data manipulation and validation.

### 3. SQL Analysis

- Queried relevant player and team statistics.
- Used filtering, grouping, sorting, and aggregate functions.
- Analysed performance metrics to identify leading players and teams.

### 4. Power BI Dashboard Development

- Imported the prepared data into Power BI.
- Created DAX measures for key performance indicators.
- Developed player rankings and performance comparisons.
- Analysed goal contributions and contributions per appearance.
- Created attacking and defensive metrics visualisations.
- Added interactive slicers to explore performance by player position.
- Designed a dedicated findings page to communicate the main insights.

## 📊 Key Areas of Analysis

- **Player Performance:** Compare player contributions and identify top performers.
- **Goal Contributions:** Examine attacking output using available goal and assist data.
- **Player Efficiency:** Compare goal contributions relative to appearances.
- **Player Rankings:** Rank players using DAX measures.
- **Attacking Performance:** Explore available attacking metrics.
- **Defensive Performance:** Compare available defensive statistics.
- **Interactive Analysis:** Filter and compare results by player position and other available dimensions.

## 🚀 How to Run the Project

1. Clone or download this repository.

2. Open the Jupyter Notebook in Jupyter Notebook or JupyterLab.

3. Install the required Python libraries:

   ```bash
   pip install pandas numpy openpyxl matplotlib seaborn
   ```

4. Update the dataset file path in the notebook if necessary.

5. Run the notebook cells to reproduce the data preparation and analysis.

6. Import the prepared data into MySQL and execute the SQL scripts, if applicable.

7. Open the Power BI `.pbix` file in Microsoft Power BI Desktop to explore the dashboard.
